# kadry/

Procesy pracownicze: od zatrudnienia po zakończenie współpracy, urlopy,
dyscyplina pracy, wynagrodzenia.

- [`onboarding-pracownika.md`](onboarding-pracownika.md) — wdrożenie
  nowego pracownika, nadanie dostępów do systemów.
- [`offboarding-pracownika.md`](offboarding-pracownika.md) — zakończenie
  współpracy: rozliczenie zobowiązań, karta obiegowa, odebranie
  dostępów; obejmuje też zwolnienie dyscyplinarne (art. 52 Kp) i
  ochronę działacza związkowego.
- [`czas-pracy.md`](czas-pracy.md) — normy i rozkłady czasu pracy,
  przerwy, godziny nadliczbowe.
- [`urlopy-wypoczynkowe.md`](urlopy-wypoczynkowe.md) — wymiar, plan
  urlopów, urlop na żądanie, zwolnienia okolicznościowe.
- [`odpowiedzialnosc-porzadkowa.md`](odpowiedzialnosc-porzadkowa.md) —
  kary porządkowe (upomnienie, nagana, kara pieniężna): tryb, terminy,
  sprzeciw.
- [`zasady-wynagradzania-i-zfss.md`](zasady-wynagradzania-i-zfss.md) —
  zasady wynagradzania oraz Zakładowy Fundusz Świadczeń Socjalnych —
  zaplecze regulaminowe, nie proces krok po kroku.

**Powiązane**: nadawanie/odbieranie dostępów do systemów — patrz
[`../it-systemy/dostepy-do-systemow.md`](../it-systemy/dostepy-do-systemow.md).
