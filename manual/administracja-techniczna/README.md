# administracja-techniczna/

Procesy związane z budynkami: przeglądy, zgłoszenia awarii, remonty,
przetargi na roboty/dostawy/usługi, gospodarka odpadami, finansowanie
termomodernizacji.

- [`przeglad-okresowy-budynku.md`](przeglad-okresowy-budynku.md) —
  przeglądy budowlane (roczny, 5-letni), ppoż (gaśnice, IBP), dozór
  techniczny dźwigów (UDT) — kto wykonuje, protokoły, książka obiektu,
  sankcje za zaniedbanie.
- [`obsluga-zgloszenia-awarii.md`](obsluga-zgloszenia-awarii.md) — od
  zgłoszenia mieszkańca do zamknięcia sprawy.
- [`odbior-techniczny-remontu.md`](odbior-techniczny-remontu.md) —
  potwierdzenie, że remont wykonano zgodnie z umową, przed rozliczeniem.
- [`procedura-przetargowa.md`](procedura-przetargowa.md) — wybór
  wykonawcy/dostawcy (roboty, dostawy, usługi): progi kwotowe, tryby,
  Komisja Przetargowa; zawiera też analizę, czy Prawo zamówień
  publicznych dotyczy Spółdzielni (co do zasady nie).
- [`przetarg-i-najem-lokali.md`](przetarg-i-najem-lokali.md) — osobna
  procedura: przetarg (licytacja) na zbycie/wynajem lokali i garaży
  odzyskanych przez Spółdzielnię.
- [`gospodarka-odpadami.md`](gospodarka-odpadami.md) — obowiązki
  Spółdzielni wobec Gminy Łódź (deklaracje, segregacja) i naliczanie
  opłat za odpady komunalne.
- [`premia-termomodernizacyjna-remontowa.md`](premia-termomodernizacyjna-remontowa.md) —
  dofinansowanie remontów/termomodernizacji z Funduszu BGK: warunki,
  wysokość premii, audyt energetyczny/remontowy.

**Powiązane**: finansowanie remontów z funduszu remontowego — patrz
[`../czynsze-ksiegowosc/rozliczenie-funduszu-remontowego.md`](../czynsze-ksiegowosc/rozliczenie-funduszu-remontowego.md).
