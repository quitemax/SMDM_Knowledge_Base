# zarzad/

Procesy zarządcze: jak Zarząd pracuje i podejmuje decyzje, sprawy
członkowskie i statutowe, które do niego należą.

- [`zasady-dzialania.md`](zasady-dzialania.md) — jak Zarząd pracuje:
  posiedzenia, kworum, głosowanie, podział kompetencji, tryb obiegowy.
- [`podejmowanie-uchwal.md`](podejmowanie-uchwal.md) — formalny tryb
  podejmowania uchwał w sprawach zastrzeżonych dla Zarządu (§ 57
  Statutu).
- [`przygotowanie-walnego-zgromadzenia.md`](przygotowanie-walnego-zgromadzenia.md) —
  zwołanie i przygotowanie Walnego Zgromadzenia zgodnie z wymogami
  statutu.
- [`przyjmowanie-w-poczet-czlonkow.md`](przyjmowanie-w-poczet-czlonkow.md) —
  przyjęcie w poczet członków, ustanawianie praw do lokali, zamiana
  mieszkań, ustanie członkostwa.
- [`obsluga-reklamacji-mieszkancow.md`](obsluga-reklamacji-mieszkancow.md) —
  skargi mieszkańców eskalowane do Zarządu, gdy nie rozwiązano ich na
  poziomie administracji osiedlowej.

**Powiązane**: skład i kompetencje Zarządu jako organu — patrz
[`../struktura-organizacyjna/organy-spoldzielni.md`](../struktura-organizacyjna/organy-spoldzielni.md).
