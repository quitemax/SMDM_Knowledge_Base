# struktura-organizacyjna/

Kto jest kim w Spółdzielni, komu podlega, jakie stanowiska istnieją.

- [`organy-spoldzielni.md`](organy-spoldzielni.md) — Walne Zgromadzenie,
  Rada Nadzorcza, Zarząd: skład, kompetencje, tryb działania — skrót
  statutu jako punkt wejścia do tematu.
- [`struktura-i-hierarchia.md`](struktura-i-hierarchia.md) — piony,
  podległość służbowa, skróty stanowisk (PM, FC, TT itd.), komisje poza
  strukturą etatową.
- [`stanowiska-i-zakresy-obowiazkow.md`](stanowiska-i-zakresy-obowiazkow.md) —
  opis roli każdego stanowiska (Zarząd i pozostałe piony) — bez nazwisk,
  to opis ROLI, nie CV konkretnej osoby.
- [`mapa-zastepowalnosci.md`](mapa-zastepowalnosci.md) — kto zastępuje
  kogo podczas urlopu/choroby, z perspektywy kompetencji.
- [`podzial-terenowy.md`](podzial-terenowy.md) — które budynki/rejony
  obsługuje która administracja osiedlowa.
- [`ochrona-danych-osobowych.md`](ochrona-danych-osobowych.md) —
  obowiązki RODO Spółdzielni jako administratora danych, rola
  stanowiska PRO.

**Powiązane**: zasady działania poszczególnych organów opisane są
osobno w [`../zarzad/`](../zarzad/) i [`../rada-nadzorcza/`](../rada-nadzorcza/).
