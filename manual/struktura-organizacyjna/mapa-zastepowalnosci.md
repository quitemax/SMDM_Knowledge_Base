# Mapa zastępowalności

Kto zastępuje kogo podczas urlopu/choroby — z perspektywy kompetencji
(nie haseł/dostępów, to osobny temat — patrz
[`../it-systemy/dostepy-do-systemow.md`](../it-systemy/dostepy-do-systemow.md)).

## Co wiadomo z regulaminów

- **Prezes Zarządu** — w czasie jego nieobecności obowiązki wykonuje
  **Członek Zarządu – Główny Księgowy** (Regulamin Zarządu, § 9 ust. 3
  i § 14 ust. 2 — to jedyne wprost nazwane zastępstwo w regulaminach).
- Każdy członek Zarządu ma obowiązek **informować Radę Nadzorczą o
  planowanym urlopie i wskazać zastępującego go pracownika** (Regulamin
  Zarządu § 9 ust. 2) — czyli zastępstwo jest ustalane ad hoc przy
  każdym urlopie, a nie zapisane raz na stałe w regulaminie.
- Inspektor ds. administracyjno-eksploatacyjnych (stanowisko TA) ma w
  swoim zakresie obowiązków wprost wpisane **zastępstwo drugiego
  pracownika na tym samym stanowisku podczas jego nieobecności** — czyli
  przynajmniej dla tego stanowiska istnieje stały, sparowany układ
  zastępstw (dwie osoby na tym samym stanowisku zastępują się wzajemnie).

## DO UZUPEŁNIENIA

Dla pozostałych stanowisk (PM, PR, PRO, PP, PB, FC, FK, FR, TT, TP, TAT,
TM, TK) regulaminy nie precyzują stałych zastępstw. Żeby ta mapa była
kompletna, potrzeba odpowiedzi (od osób faktycznie zarządzających danym
pionem) na pytanie: **kto przejmuje zadania danego stanowiska, gdy ta
osoba jest nieobecna (urlop/choroba) dłużej niż kilka dni?**

| Stanowisko | Kto zastępuje | Uwagi |
|---|---|---|
| Prezes Zarządu | Członek Zarządu – Główny Księgowy | ustalone w regulaminie |
| Członek Zarządu – Główny Księgowy | DO UZUPEŁNIENIA | |
| Członek Zarządu ds. techniczno-eksploatacyjnych | DO UZUPEŁNIENIA | |
| PM | DO UZUPEŁNIENIA | |
| PR (obsługa prawna) | DO UZUPEŁNIENIA | |
| PP (kadry/sekretariat) | DO UZUPEŁNIENIA | |
| FC (czynsze/windykacja) | DO UZUPEŁNIENIA | |
| FK (płace/księgowość) | DO UZUPEŁNIENIA | |
| FR (wkłady/rozliczenia) | DO UZUPEŁNIENIA | |
| TT (nadzór techniczny) | DO UZUPEŁNIENIA | |
