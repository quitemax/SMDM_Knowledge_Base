Zasady działania Rady Nadzorczej: jak pracuje, jak wybiera Zarząd, jakie
ma stałe komisje.

  zwoływanie posiedzeń, kworum, głosowanie, status postanowień.
- [`podejmowanie-uchwal.md`](podejmowanie-uchwal.md) — formalny tryb
