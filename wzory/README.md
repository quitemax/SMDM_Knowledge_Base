# Wzory dokumentów

Wzory wniosków, oświadczeń i innych formularzy do pobrania ze strony
Spółdzielni (<https://smdmlodz.pl/do-pobrania/>), pobrane 2026-10-03.

- `pdf/` — oryginalne pliki PDF (nazwy znormalizowane: małe litery, myślniki,
  bez znaków diakrytycznych; adres pierwotnego pliku jest w polu `source_url`
  w front matter odpowiadającego pliku md).
- `md/` — wersje Markdown. Puste pola formularza zapisano jako wielokropek
  (`…………`), treść stałą przepisano bez zmian z PDF-u. Przy sporach zawsze
  obowiązuje PDF (patrz [`../zrodla/README.md`](../zrodla/README.md)).

Lista dokumentów i ich opisy są w polach `title` i `summary` front matter
każdego pliku md. Wzór zawiera tylko puste pola do wypełnienia — nie
umieszczaj tu wypełnionych formularzy (dane osobowe).
